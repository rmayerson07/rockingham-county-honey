# Rockingham County Honey Co

Marketing site for Rockingham County Honey Co — a family apiary in Stratham, New Hampshire.

Static site, no build step. `index.html` plus `assets/`.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy

Deployed on Vercel as a static site — no framework, no build command, output directory is the repo root.
